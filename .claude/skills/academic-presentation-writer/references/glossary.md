# Словарь терминов мини-курса «Введение в CTF»

Назначение: единые формы терминов для всех лекций и условий заданий. Правила пользования:

1. **Первое употребление** — русская форма с английским эквивалентом в скобках: «обратная разработка (reverse engineering)»; далее — одна выбранная форма без чередования синонимов.
2. **Жаргон CTF** допустим в форме из столбца «Допустимый жаргон» — после того как термин введён полной формой. В заголовках слайдов и определениях использовать каноническую форму.
3. **Идентификаторы** (CVE, номера RFC, версии, имена функций и опций) не изменять без проверки по первоисточнику.
4. Словарь — живой: устоявшийся в новой лекции термин дописывать в соответствующий раздел.

## Общие понятия безопасности

| Каноническая форма | EN | Употребление |
|---|---|---|
| уязвимость | vulnerability | не «дыра», не «баг» (ошибка ≠ уязвимость) |
| эксплуатация уязвимости | exploitation | — |
| эксплойт | exploit | допустим как термин; не «сплойт» |
| полезная нагрузка | payload | после введения допустимо «payload» латиницей |
| поверхность атаки | attack surface | — |
| повышение привилегий | privilege escalation | не «эскалация» |
| удалённое выполнение кода | remote code execution, RCE | после введения — RCE |
| подтверждение концепции | proof of concept, PoC | после введения — PoC |
| перебор | brute force | не «брутфорс», не «брут» |
| стенд | lab environment | учебная среда для запуска заданий |
