# Название задания

> Категория: misc · Сложность: easy · 100 очков

Условие задания: что дано участнику и что требуется найти. Легенда — не более
двух-трёх предложений; существенные для решения сведения не должны прятаться в ней,
а подсказок к решению в условии быть не должно.

**Доступ:** `http://<host>:<порт>` — только для задания с сервисом.

**Файлы:** `public/…`

**Инструменты:**

- инструмент — команда установки.

**Локальный запуск:** только если `deploy/` выдаётся участнику (`handout: [deploy]`).

**Формат флага:** `BootCTF{...}`
