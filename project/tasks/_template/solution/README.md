# Решение: Название задания

**Идея.** Одно-два предложения: какая уязвимость или приём лежит в основе задания
и чему оно учит.

## Ход решения

1. Первичный анализ: что видно в выданных материалах.
2. Ключевое наблюдение.
3. Получение флага.

```console
$ python3 solve.py
BootCTF{...}
```

## Комментарий для преподавателя

Типичные затруднения участников, подсказки по нарастающей, связь с материалом лекции.
