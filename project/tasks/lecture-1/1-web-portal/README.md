# Портал

> Категория: web · Сложность: easy · 100 очков

## Легенда

ООО «Северный маяк» заказало аудит своего клиентского портала — простого веб-сервиса
на Python. Разработчики спешили и оставили в коде несколько служебных заметок, которые
не должны были попасть в рабочую версию. Найдите их.

## Доступ

Портал доступен по адресу `http://<host>:8001` (на занятии `<host>` — адрес стенда
преподавателя; для локальной копии — `localhost`).

## Инструменты

- любой браузер с инструментами разработчика (DevTools: `F12`);
- `curl` — отправка HTTP-запросов из командной строки
  (Linux: `sudo apt install curl`);
- `base64` (входит в coreutils, уже есть в Linux).

Специальных установок не требуется: всё решается браузером и `curl`.

## Что нужно

Требуется найти флаги формата `BootCTF{...}`, спрятанные в портале.

**Формат флага:** `BootCTF{...}`
