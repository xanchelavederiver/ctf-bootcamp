# Портал

> Категория: web · Сложность: easy · 100 очков

ООО «Северный маяк» заказало аудит своего клиентского портала — простого веб-сервиса
на Python. Разработчики спешили и оставили в коде несколько служебных заметок, которые
не должны были попасть в рабочую версию. Найдите их: в портале спрятано несколько флагов.

**Доступ:** `http://<host>:8001`, где `<host>` — адрес стенда преподавателя (на занятии)
или `localhost` (локальная копия).

**Инструменты:**

- браузер с инструментами разработчика (DevTools, `F12`);
- `curl` — `sudo apt install curl`;
- `base64` — входит в coreutils.

**Локальный запуск:** из каталога `deploy/` — `docker compose up --build`; флаги в
локальной копии учебные (`BootCTF{default_...}`), на стенде преподавателя они другие.

**Формат флага:** `BootCTF{...}`
