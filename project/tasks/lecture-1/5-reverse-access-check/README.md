# Пропуск

> Категория: reverse · Сложность: easy · 100 очков

Аудит ООО «Северный маяк» нашёл в архиве подрядчика маленькую утилиту проверки
пропусков `access-check`. Она спрашивает пропуск и отвечает `Access granted`
или `Access denied`. Говорят, у неё три рабочих пропуска, а не один.

Найдите все три.

**Файлы:** `public/access-check` — исполняемый файл ELF для Linux x86-64.

**Запуск:**

```console
$ chmod +x access-check
$ ./access-check
<ввод пропуска>
```

**Формат флага:** `BootCTF{...}`. Каждый из трёх пропусков — отдельный флаг.
