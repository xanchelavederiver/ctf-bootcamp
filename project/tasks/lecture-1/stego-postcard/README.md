# Открытка

> Категория: стеганография (stego) · Сложность: easy · 100 очков

В ходе аудита ООО «Северный маяк» на корпоративном файловом сервере нашлась
безобидная с виду открытка — картинка `postcard.png`. Сотрудник службы безопасности
уверен, что в ней что-то спрятано: слишком уж аккуратно она сделана.

Исследуйте изображение. В нём спрятано несколько флагов — начните с самого простого
(метаданные), затем загляните в отдельные биты и каналы картинки.

**Файлы:** `public/postcard.png`

**Формат флага:** `BootCTF{...}`

Найдено не всё — часть флагов спрятана глубже. Если в классе успели добраться
не до всех, продолжайте дома: в открытке есть что поискать.
