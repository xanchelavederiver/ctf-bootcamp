# Турникет

> Категория: pwn · Сложность: easy · 100 очков

При аудите ООО «Северный маяк» нашли сетевую службу проходной — «турникет».
Она принимает пропуск и отвечает, впускать ли посетителя. Код проверки написан
небрежно. Заставьте службу выдать флаг.

**Доступ:** `nc <host> 9001`, где `<host>` — адрес стенда преподавателя (на занятии)
или `127.0.0.1` (локальная копия).

**Файлы:** `public/gatekeeper` — исполняемый файл службы (ELF x86-64) и его исходный
текст `public/gatekeeper.c`. Служба на сервере запускает именно этот бинарь.

**Инструменты:**

- [pwntools](https://docs.pwntools.com/) — `pip install pwntools`;
- отладчик `gdb` (желательно с [pwndbg](https://github.com/pwndbg/pwndbg));
- `nc` (netcat) — для ручных проб.

**Локальный запуск:** из каталога `deploy/` — `docker compose up --build`; флаг в
локальной копии учебный (`BootCTF{default_...}`), на стенде преподавателя он другой.

**Формат флага:** `BootCTF{...}`
