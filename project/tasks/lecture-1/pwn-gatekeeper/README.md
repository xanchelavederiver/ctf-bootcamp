# Турникет

> Категория: pwn · Сложность: easy · 100 очков

При аудите ООО «Северный маяк» нашли сетевую службу проходной — «турникет».
Она принимает пропуск и отвечает, впускать ли посетителя. Код проверки написан
небрежно: в нём есть функция, печатающая служебный флаг, но вызывается она только
«для отладки». Доберитесь до неё.

**Подключение:**

```sh
nc <host> 9001
```

`<host>` — адрес стенда преподавателя (в аудитории) или `127.0.0.1`, если вы
подняли задание локально (`docker compose up --build` в каталоге `deploy/`).

**Файлы:** `public/gatekeeper` — исполняемый файл службы (ELF x86-64), и его
исходный текст `public/gatekeeper.c`. Служба на сервере запускает ровно этот бинарь.

**Нужные инструменты (x86-64 Linux):**

- [pwntools](https://docs.pwntools.com/) — `pip install pwntools`;
- отладчик `gdb` (желательно с [pwndbg](https://github.com/pwndbg/pwndbg));
- `nc` (netcat) для ручных проб.

Всё перечисленное уже есть в образе `ctf-toolbox` (см. `tasks/docs/toolbox.md`).

**Формат флага:** `BootCTF{...}`

Подсказка: сравните размер буфера в `gatekeeper.c` с тем, сколько байт служба
готова прочитать.
