# Решение: Открытка (stego)

**Идея.** Одно изображение PNG несёт четыре независимых тайника, каждый —
отдельный базовый приём стеганографии: метаданные, бит-плоскость канала,
младший значащий бит (LSB) канала и данные, дописанные после конца файла.
Задание показывает, что «картинка» — это несколько слоёв, и каждый слой
просматривается своим инструментом.

Флаги (`public/postcard.png` воспроизводимо собирается `src/generate.py`):

| № | Где | Приём | Инструмент | Когда |
|---|-----|-------|-----------|-------|
| 1 | tEXt-метаданные (ключ `Comment`) | чтение метаданных | `exiftool`, `strings` | в классе |
| 2 | бит-плоскость 0 красного канала (нарисованный текст) | просмотр бит-плоскостей | StegSolve, Aperi'Solve | в классе |
| 3 | LSB синего канала, построчно | извлечение LSB | `zsteg` | класс/дома |
| 4 (скрытый) | ZIP, дописанный после чанка IEND | данные после конца файла | `zsteg`/`unzip` | дома |

## Ход решения

1. **Флаг 1 — метаданные.** `exiftool postcard.png` показывает поле `Comment` с флагом.
   Тот же результат даёт `strings postcard.png | grep BootCTF` (tEXt хранится текстом).

2. **Флаг 2 — бит-плоскость.** Открыть картинку в StegSolve и листать плоскости
   (кнопки `<` / `>`), пока на «Red plane 0» не проступит белый текст на чёрном фоне.
   Онлайн-аналог без установки — Aperi'Solve: загрузить файл и посмотреть раздел
   «bit planes». Флаг нужно прочитать глазами.

3. **Флаг 3 — LSB синего канала.** `zsteg -a postcard.png` перебирает способы и
   выводит строку для селектора `b1,b,lsb,xy` — это и есть флаг (1 бит, синий канал,
   построчно). Точечно: `zsteg -E b1,b,lsb,xy postcard.png`.

4. **Флаг 4 (скрытый) — приписанный ZIP.** `zsteg` в конце отчёта сообщает
   `extradata: … Zip archive data`. Файл — валидный PNG и валидный ZIP одновременно:
   `unzip postcard.png` (предупредит про «extra bytes», но извлечёт `secret.txt`).

```console
$ python3 solve.py
BootCTF{png_text_chunk_meta}
BootCTF{bitplane_red_art}
BootCTF{blue_lsb_row_major}
BootCTF{zip_after_iend_chunk}
```

`solve.py` читает все четыре флага программно (Pillow + stdlib `zipfile`); флаг 2
распознаётся по тому же шрифту 5x7, которым он нарисован в `src/generate.py`.

## Комментарий для преподавателя

- **Порядок на занятии.** Показать флаг 1 (метаданные) и флаг 3 (`zsteg -a`) —
  это два «рабочих» инструмента форензики/стего. Флаг 2 хорош для живой демонстрации
  StegSolve: видно, как «пустая» плоскость вдруг превращается в текст. Флаг 4
  (скрытый) оставить на дом — не называть его на слайдах.
- **Подсказки по нарастающей:**
  1. «Картинка — это не только пиксели. Что ещё хранит файл?» (метаданные);
  2. «Один бит в пикселе может быть лишним. Посмотрите каждый бит отдельно»
     (бит-плоскости, StegSolve);
  3. «`zsteg` умеет перебирать способы сам: `zsteg -a`»;
  4. «PNG заканчивается на IEND. А файл — на IEND?» (данные после конца файла).
- **Типичные затруднения:** путают бит-плоскость (визуальный приём) и LSB-поток
  (байты); пытаются прочитать флаг 3 глазами в StegSolve вместо `zsteg`; не замечают
  приписанный архив, потому что картинка открывается как обычно.
- **Про инструменты.** `zsteg` — лучший первый инструмент для PNG/BMP (сам находит
  LSB-тайники). StegSolve — для визуального просмотра плоскостей. Aperi'Solve —
  онлайн, без установки, объединяет оба подхода. Приписанный ZIP достают
  `binwalk` или `unzip`.
- **Связь с лекцией:** раздел «стеганография», слайды задания `stego/postcard`.
