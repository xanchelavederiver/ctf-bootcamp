# Резервная копия

> Категория: forensics · Сложность: medium · 150 очков

## Легенда

Аудит ООО «Северный маяк». Резервные копии выгружались на внутренний FTP-сервер, и
служба эксплуатации сняла дамп сетевого трафика за один сеанс обмена. Дамп попал к
вам. Задача — разобраться, что и как передавалось, и что из этого можно восстановить.

## Что дано

**Файл:** `public/capture.pcapng` — дамп сетевого трафика (packet capture) одного
сеанса работы с FTP-сервером: вход, просмотр каталога и загрузка двух файлов.

В аудитории может быть поднят **живой FTP-сервер** стенда по адресу `<host>:2121` —
тот же, с которого снят дамп.

## Что нужно

Найти флаги формата `BootCTF{...}`. Часть находится прямо в дампе, часть потребует
поработать с загруженными файлами, а ещё часть — для домашней работы: на лекции
находят не всё, **ищите дальше дома**.

## Инструменты

| Инструмент | Зачем | Установка |
|---|---|---|
| **Wireshark** | просмотр дампа, Follow TCP Stream, экспорт объектов | GUI; `apt install wireshark` |
| `tshark` | то же из командной строки | `apt install tshark` |
| `unzip` / `zipinfo` | просмотр и распаковка архива | `apt install unzip` |
| `fcrackzip` | подбор пароля архива по словарю | `apt install fcrackzip` |
| FTP-клиент (`ftp`, `curl`) | подключение к живому серверу | обычно уже установлен |

Все перечисленные инструменты уже есть в образе `ctf-toolbox` (см. `docs/toolbox.md`).
Словарь паролей John лежит там по пути `/usr/share/john/password.lst`.

**Формат флага:** `BootCTF{...}`
