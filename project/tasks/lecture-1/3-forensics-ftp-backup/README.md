# Резервная копия

> Категория: forensics · Сложность: medium · 150 очков

Аудит ООО «Северный маяк». Резервные копии выгружались на внутренний FTP-сервер, и
служба эксплуатации сняла дамп сетевого трафика во время одного сеанса обмена. Дамп
попал к вам. Разберитесь, что и как передавалось и что из этого можно восстановить.
Флагов несколько.

**Доступ:** в аудитории может быть поднят живой FTP-сервер стенда — `<host>:21`, тот же,
с которого снят дамп; `<host>` — адрес стенда преподавателя.

**Файлы:** `public/capture.pcapng` — дамп сетевого трафика (packet capture) одного
сеанса работы с FTP-сервером.

**Инструменты:**

- Wireshark (GUI) или `tshark` — `sudo apt install wireshark tshark`;
- `unzip` — `sudo apt install unzip`;
- `fcrackzip`, `john` — `sudo apt install fcrackzip john`;
- FTP-клиент (`ftp`, `curl`) — обычно уже установлен.

**Формат флага:** `BootCTF{...}`
