# Шифратор

> Категория: криптография (`crypto`) · Сложность: medium · 150 очков

ООО «Северный маяк» вынесло шифрование во внутреннюю службу. Аудит показал, что
в ней хватает слабых мест: где-то «шифрование» оказывается простым кодированием,
где-то ключ можно вытащить из самой же службы, а резервная копия защищена ключом,
выведенным из времени. Ваша задача — пройтись по этим слабостям и собрать флаги.

## Доступ

Служба отвечает по HTTP:

```
http://<host>:8002/
```

`<host>` — адрес стенда лектора (на занятии) или `localhost` (если поднимаете
копию сами, см. ниже). Главная страница перечисляет служебные конечные точки.

**Выданный файл:** `public/backup.tar` — резервная копия с внутренним инструментом
шифрования и зашифрованным отчётом.

## Нужные инструменты

- `curl` — отправка HTTP-запросов (`sudo apt install curl`);
- `base64` — кодирование и декодирование (входит в `coreutils`, уже есть в Linux);
- Python 3 с библиотекой `pycryptodome` — для разбора резервной копии
  (`pip install pycryptodome`; либо готовый образ `ctf-toolbox`, см. `tasks/docs/toolbox.md`).

Всё решается из командной строки: ни браузер, ни специальные программы не обязательны.

## Локальный запуск (необязательно)

Свою копию службы можно поднять из каталога задания — флаги в ней будут
учебные (`BootCTF{default_...}`), на стенде лектора флаги другие:

```sh
cd deploy && docker compose up --build    # http://127.0.0.1:8002
docker compose down                       # остановить
```

## Формат флага

`BootCTF{...}`

На странице перечислены три конечные точки, и у службы есть ещё одна слабость сверх
очевидных. На лекции находят не всё — **ищите дальше дома**.
