# Шифратор

> Категория: crypto · Сложность: medium · 150 очков

ООО «Северный маяк» вынесло шифрование во внутреннюю службу. Аудит показал, что
в ней хватает слабых мест. Найдите эти слабости и соберите флаги — их несколько.

**Доступ:** `http://<host>:8002`, где `<host>` — адрес стенда преподавателя (на занятии)
или `localhost` (локальная копия). Главная страница перечисляет служебные конечные точки.

**Файлы:** `public/backup.tar` — резервная копия с внутренним инструментом шифрования
и зашифрованным отчётом.

**Инструменты:**

- `curl` — `sudo apt install curl`;
- `base64` — входит в coreutils;
- Python 3 с библиотекой `pycryptodome` — `pip install pycryptodome`.

**Локальный запуск:** из каталога `deploy/` — `docker compose up --build`; флаги в
локальной копии учебные (`BootCTF{default_...}`), на стенде преподавателя они другие.

**Формат флага:** `BootCTF{...}`
