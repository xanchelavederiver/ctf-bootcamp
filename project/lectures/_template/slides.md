# Заголовок формулирует тезис слайда, а не его рубрику

Основной текст слайда — тезис и его компактное обоснование: то, что аудитория
успевает прочитать, пока слушает.

- при первом употреблении термин даётся с английским эквивалентом:
  **эксплуатация уязвимости (exploitation)**;
- далее используется одна выбранная форма;
- имена файлов, команд и функций набираются моноширинным шрифтом: `strings`, `/etc/passwd`;
- ссылка на слайде кликабельна: [название ресурса](https://example.org/source-1).

> **Определение.** Врезка-цитата выделяет определение или ключевой тезис слайда.

# Команды и их вывод оформляются как транскрипт терминала

<div class="cols c-3-2">
<div>

```console
$ file ./task
task: ELF 64-bit LSB executable, x86-64, dynamically linked, not stripped
$ strings -n 8 ./task | grep -i flag
Enter the flag:
```

</div>
<div>

1. `file` определяет формат и архитектуру файла.
2. `strings` извлекает печатные последовательности — первый шаг статического анализа.

</div>
</div>

<div class="note">

**Примечание.** Блок `console` — для команд с выводом; исходный код оформляется
блоком с указанием языка (`c`, `python`, `asm`).

</div>

# Исходный код и сравнение по единым критериям

<div class="cols">
<div>

```c
char buf[32];
gets(buf);          /* (1) длина ввода не ограничена */
```

```python
from pwn import *

io = process("./task")
io.sendline(b"A" * 40)   # (2)
```

</div>
<div>

| Критерий | Статический анализ | Динамический анализ |
|---|---|---|
| Запуск программы | не требуется | требуется |
| Объект изучения | код и данные файла | поведение процесса |

<div class="warn">

**Ограничение.** Врезка `warn` — для условий применимости и типичных ошибок.

</div>

</div>
